# Professional Portfolio — Zarak Afridi

A premium, modern, and minimalist professional portfolio showcasing cybersecurity expertise, academic achievements, certifications, and projects. 

This portfolio has been completely modernized with a sleek dark-mode aesthetic, fluid typography (Outfit & Inter), optimized performance for mobile devices, and highly responsive components.

---

## 🚀 Key Features

* **SaaS-Minimalist Aesthetic**: Completely customized using curated color palettes, subtle dark gradients, and smooth hover effects.
* **Fluid Scroll-Hiding Navbar**: On mobile devices, the sticky top navigation automatically slides out of view on scroll-down to maximize readability and slides back in on scroll-up.
* **Performance-Optimized Background**: Features a lightweight interactive particle background that automatically deactivates on mobile platforms to prevent animation stutter and ensure smooth scrolling.
* **Lean Certificates Directory**: Replaces legacy overlays with a modern horizontal layout on mobile, keeping category badges cleanly integrated inside text containers off the images.
* **Compact Interests Pills**: Interests/hobbies display as long rows on desktop and automatically scale down to sleek `1cm by 4cm` horizontal capsules (pills) side-by-side on mobile, hiding heavy descriptions for a neat look.
* **Responsive Layouts**: Fully responsive flexbox/grid components ensuring a first-class experience on mobile, tablet, and desktop monitors.

---

## 🛠️ Technology Stack

* **Structure**: HTML5 (Semantic Structure)
* **Styling**: Vanilla CSS3 (Custom Properties / HSL Colors / Media Queries)
* **Interactions**: Modern JavaScript (Intersection Observer API / Platform Detection / Scroll Handlers)
* **Icons**: Font Awesome

## 💻 Local Development

To run this project locally, start a simple HTTP server in the repository root directory.

### Using Python 3:
```bash
python3 -m http.server 3000
```

### Using Node.js (http-server):
```bash
npx http-server -p 3000
```

Once running, access the local server in your browser at:
👉 **`http://localhost:3000/zeex/`**
